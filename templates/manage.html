Admin

Add answer keys and subjects, and publish marks from many OMR sheets at once. Changes are saved to the website's GitHub repository and show on the site about 1 to 2 minutes later.

1. Connect to GitHub

How do I get a token?
  1. Open GitHub › Settings › Fine-grained tokens › Generate new token.
  2. Repository access: Only select repositories, and pick this website's repository.
  3. Permissions › Repository permissions › Contents: Read and write.
  4. Generate, copy the token and paste it above. Keep it secret: anyone with it can change the website.

Answer keys

Number of answers saved for each subject and set.

One row per question: question number, then the answer for each set (A1 B1 C1 D1), as in the published key PDF. Rows you leave out keep their saved answer. Use 23 when two options are accepted and X for a dropped question.

Subjects (papers)

Add a new subject

For a paper that uses the same OMR sheet (100 questions, options 1 to 5, sets {{ cfg.set_codes|join(", ") }}). After adding it, add its answer keys in the Answer keys tab.

Bulk scan & publish

Choose the subject, then select all the OMR sheet photos for that subject. Sheets are read on this computer; photos are not uploaded. Check the register and booklet numbers, then publish. Candidates see their marks on the Results page by typing both numbers.
