Admin

Add answer keys and subjects, and publish marks from many OMR sheets at once. Changes are saved to the website's GitHub repository and show on the site about 1 to 2 minutes later.

Sign in

This page is not linked anywhere on the site and is hidden from search engines. Even if someone finds the address, they can't change anything without your GitHub token, and they can't see the OMR sheets without your admin passphrase.

No admin passphrase has been set yet. Choose one now (at least 10 characters) and type it again. Write it down: without it the saved OMR sheets can't be opened, and nobody can recover it.

How do I get a token?
  1. Open GitHub › Settings › Fine-grained tokens › Generate new token.
  2. Resource owner: your account. Repository access: Only select repositories, and pick this website's repository.
  3. Permissions › Repository permissions › Contents › change "Read-only" to Read and write. (Metadata: Read-only is added by itself. Nothing else is needed.)
  4. Already made a token? Open it under Fine-grained tokens, press Edit, fix the two settings above and save. The token text stays the same.
  5. Generate, copy the token and paste it above. Keep it secret: anyone with it can change the website.

Answer keys

Number of answers saved for each subject and set.

The answers are read into the box below. Check them, press Check to see a preview, then Save. Photos of a key cannot be read; type those in.

One row per question: question number, then the answer for each set (A1 B1 C1 D1), as in the published key PDF. Rows you leave out keep their saved answer. Use 23 when two options are accepted and X for a dropped question.

Add one sheet

For any exam and subject. Type the candidate's answers, or (for exams whose OMR sheet the site can read) fill them in from a photo and correct anything that is wrong. Attaching a photo is optional; candidates can view it with their result.

Use the option number for each question, 0 for no bubble shaded, and * for more than one shaded. Every question needs an entry.

Fetch OMR sheets from a KEA link

Paste the KEA "View OMR Records" link. GitHub then goes through every district, subject and exam centre on that page, downloads each centre's OMR sheets, scores them and publishes them, and adds them to Search by register no. and the Merit list. It runs on GitHub, so you can close this page.

To avoid overloading KEA's server it asks for one page about every 20 seconds, waits when KEA says "too many requests", and stops if KEA shows a captcha (it never tries to get past one). A whole exam can take many hours. Progress is saved after every centre and it carries on by itself about every 3 hours until done.

KEA subjects are matched to this exam's subjects by name (for example "General Knowledge (PAPER -1)" to Paper I: General Knowledge). Subjects with no match are skipped and listed below.
